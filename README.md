# 🕷️ Spider Solitaire 蜘蛛纸牌

一个自包含、单文件的 Spider Solitaire 网页游戏，无需安装、无需构建，浏览器直接打开 `index.html` 即玩。

**[▶ 在线试玩](https://BOCByF.github.io/spiderSolitaire/)**

## 功能

- **三难度切换**：单花色 / 双花色 / 四花色
- **标准蜘蛛纸牌规则**：
  - 10 列，发牌补 5 轮（每轮每列 +1 张）
  - 可移动延伸到列顶的连续同花色降序顺联（不可移动的牌会显示锁定阴影）
  - 完成整叠同花色 K→A 自动收蛇
  - 拖拽实时跟随手指，回拖原位即可取消操作
- **智能落位**：点击自动移动时优先落到能形成最长顺列的目标
- **撤销 / 提示 / 计分**
- 精美 CSS 动画（发牌入场、收蛇弹出）

## 玩法

- **拖拽**：按住一张牌（或一连串连续同花降序牌），拖到目标列顶部（顶牌比它大 1 或空列）；拖回原列可取消
- **点击**：点击可移动牌自动移动到最近的合法位置
- **发牌按钮**：蛇区右侧的牌背，点击发下一轮
- **目标**：凑满 8 组同花色 K→A 即获胜

## 技术

单文件纯 HTML + CSS + JavaScript（无依赖、无构建、无 CDN），完全离线可用，响应式适配手机。

## 运行

```bash
# 方式1：直接双击 index.html 在浏览器打开
# 方式2：起本地服务器
python3 -m http.server 8891
# 然后访问 http://localhost:8891/
```
